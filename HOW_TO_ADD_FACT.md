# Как добавить факт в «Cultura»

Факты лежат в `data/facts.json`, в массиве `"facts"`. Новый факт дописывается в конец массива.

## Формат

```json
{
  "c": "cultura",
  "t": "Сиеста",
  "es": "La siesta",
  "x": "Короткий дневной отдых после обеда. Сегодня в больших городах её почти не соблюдают, но слово знают все.",
  "img": "paella",
  "src": null
}
```

| Поле  | Что это | Обязательно |
|-------|---------|-------------|
| `c`   | Категория: `historia` (история Испании), `idioma` (испанский язык), `latam` (Латинская Америка), `cultura` (культура и быт) | да |
| `t`   | Заголовок по-русски | да |
| `es`  | Фраза по-испански. Каждое слово в ней кликабельно: перевод и озвучка | нет, можно `""` |
| `x`   | Сам факт, 1–3 предложения по-русски | да |
| `img` | Наклейка: имя файла из `img/` без расширения или `null` | нет |
| `src` | Ключ источника из блока `"sources"` или `null` | нет |

### Наклейки, которые уже есть

`bread`, `cathedral`, `dancers`, `fish`, `flag_sevilla`, `flag_watercolor`, `flamenco`, `flowers`, `guitar_fan`, `heart_madrid`, `jamon`, `madrid_azulejo`, `malaga`, `nb_bike`, `nb_books`, `nb_flag`, `nb_hearts`, `nb_house`, `nb_stamp`, `oranges`, `paella`, `palacio_cristal`, `poster_alhambra`, `sevilla`, `spain_plate`, `spain_tile`, `stamp_sagrada`.

Новая картинка: положить файл в `img/` (лучше `.webp`, до ~300 px по ширине) и добавить строку в `data/stickers.json`: `"имя": "img/имя.webp"`.

### Источники

В `"sources"` у каждого источника есть ключ, название и ссылка:

```json
"skyeng": ["Skyeng: Испания vs Латинская Америка", "https://skyeng.ru/magazine/es/..."]
```

Новый источник добавляется туда же, а в факте указывается его ключ: `"src": "skyeng"`.

## Как попросить Claude

Достаточно написать в чат:

> добавь факт: Ла Томатина — праздник в Буньоле, где в последнюю среду августа все кидаются помидорами. Категория: культура. Фраза: La Tomatina de Buñol. Источник: https://…

Claude допишет факт в `data/facts.json`, подберёт наклейку, обновит офлайн-кеш (`python3 tools/build_sw.py`), сделает коммит и отправит на GitHub. Через минуту-две факт появится на сайте; на телефоне — после следующего открытия приложения.

## Если правишь сам

1. Допиши объект в конец `"facts"` (между фактами нужна запятая).
2. Запусти `python3 tools/build_sw.py`. Без этого телефон может долго показывать старую версию.
3. `git add -A && git commit -m "Факт: …" && git push`
