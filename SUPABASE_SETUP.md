# Синхронизация прогресса (Supabase)

Пока `supabase-config.js` пустой, сайт работает только с `localStorage`, как раньше.

## Что уже настроено

- Проект `mi-espanol` (бесплатный, Европа), таблица `progress` с правилами RLS из `supabase/schema.sql`.
- Authentication → URL Configuration: Site URL и Redirect URL — `https://mersanns.github.io/mi-espanol/`.
- Ключи вписаны в `supabase-config.js`. Publishable-ключ публичный: каждый пользователь видит только свою строку.

## Как это работает

- Вход: вкладка «Progreso» → «Синхронизация» → e-mail → ссылка из письма.
- Приложение на iPhone (с экрана «Домой»): ссылка из письма откроется в Safari. Войди там, нажми «Перенести вход в приложение» — код скопируется. Открой приложение → Progreso → вставь код в поле «Код из Safari».
- Синхронизируются коробки карточек, решённые упражнения и ответы в них, «Sobre mí», мои факты, дни занятий, очки, ошибки и режим курса.
- Состояния двух устройств сливаются, ничего не теряется: для каждой карточки и упражнения берётся последний ответ, дни и очки берутся по максимуму, факты объединяются.
- Без интернета всё сохраняется локально и уходит на сервер, когда связь вернётся.
- «Сбросить прогресс» сбрасывает прогресс на всех устройствах.
