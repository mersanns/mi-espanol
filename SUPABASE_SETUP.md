# Синхронизация прогресса

Без паролей и писем, по коду.

## Как пользоваться

1. На одном устройстве: Progreso → «Синхронизация» → **Включить синхронизацию**. Появится код вида `K7QM-3XRP-W9TD`.
2. На другом устройстве: Progreso → **У меня уже есть код** → ввести код → «Подключить».
3. Готово. Прогресс обоих устройств объединяется, дальше всё синхронизируется само.

Код — единственный ключ к прогрессу, его лучше никому не показывать. Увидеть его можно в любой момент на подключённом устройстве. «Отключить здесь» выключает синхронизацию только на этом устройстве, прогресс на нём остаётся.

## Что синхронизируется

Коробки карточек, решённые упражнения и ответы в них, «Sobre mí», мои факты, дни занятий, очки, ошибки и режим курса. Для каждой карточки и упражнения берётся последний ответ, дни и очки — по максимуму, факты объединяются. Без интернета всё копится локально и отправится, когда связь вернётся. «Сбросить прогресс» сбрасывает его на всех подключённых устройствах.

## Как устроено

- Бесплатный проект Supabase `mi-espanol`, Европа. Адрес и публичный ключ — в `supabase-config.js`.
- В базе одна закрытая таблица `sync_progress` и две функции, `sync_get` и `sync_put` (`supabase/schema.sql`). Напрямую таблицу не прочитать; через функции видна только строка, чей код знаешь. Хранится не сам код, а его SHA-256.
- Если `supabase-config.js` пустой, сайт работает только с `localStorage`.
